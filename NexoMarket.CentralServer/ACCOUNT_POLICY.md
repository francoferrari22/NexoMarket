# NexoMarket — política de cuentas 4.1.3

El correo electrónico es el identificador único de la cuenta NexoMarket.

- Un correo solo puede crear una cuenta una vez.
- Una cuenta puede ser comprador o vendedor; no se crean duplicados con el mismo correo.
- Un vendedor queda vinculado a su Store ID.
- El acceso posterior se realiza con la contraseña existente o recuperación de contraseña.
- Los datos del perfil deben conservarse junto con la cuenta y no reemplazarse por un nuevo registro.

La API central debe ser la fuente de verdad para la unicidad global cuando `web_api_url` esté configurada. La copia local de Windows se conserva como caché operativa.
