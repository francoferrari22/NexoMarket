# NexoMarket 5.2.0

## Cambios principales
- Sincronización bidireccional Web ↔ Windows para productos: Windows primero adopta cambios de Central y luego publica cambios locales nuevos, evitando rebotes y sobrescrituras.
- El login exitoso de vendedor habilita automáticamente la sincronización web.
- UI Seller Center Neon Dark Premium: negro profundo, blanco neón, verde y violeta, curvas de luz de fondo y tarjetas con glow/hover.
- Se mantiene intacto el flujo de autenticación Web ↔ Windows por correo + contraseña.
- El registro Web continúa sin teléfono y sin pedir Store ID.

## Deploy
Reemplazar el contenido del repositorio por el contenido de esta carpeta y desplegar en Render.
No modificar las variables de entorno existentes.
