# NexoMarket 5.1.6 — Login único + Upload R2

- Host oficial para Windows: https://nexomarket-0k22.onrender.com.
- Windows usa correo + contraseña; Store ID viene de Central.
- Crear cuenta desde Windows abre /seller-register en la Web.
- R2 tiene timeout de 25 segundos y devuelve el error concreto.
- GET /api/storage/test prueba escritura real en R2.
- GET /api/storage/status muestra si las credenciales R2 están cargadas.
