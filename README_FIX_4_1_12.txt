NexoMarket 4.1.12 - FIX IDENTIFICADORES DE LICENCIA

1. La licencia pertenece a la cuenta. El ID de cuenta es el identificador PRINCIPAL.
2. Store ID ahora se muestra en el panel del vendedor y puede copiarse.
3. Store ID es opcional al generar/activar una licencia; si existe, se valida como dato adicional.
4. El License Manager tiene botones para COPIAR ID DE CUENTA y COPIAR STORE ID.
5. El vendedor puede enviar solamente su ID de cuenta para solicitar la licencia.
6. COPIAR TOKEN y GUARDAR TOKEN siguen disponibles para entregar la licencia.
7. El servidor central permite tokens sin Store ID, siempre que el ID de cuenta y correo sean correctos.
8. Para que BUSCAR CUENTA funcione en Render, hay que desplegar esta version del NexoMarket.CentralServer; si Render sigue respondiendo 404, esta ejecutando una version anterior.
9. No se usa Machine ID para determinar la licencia.
